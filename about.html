DevOps Lab 1 — Kiến thức & Trải nghiệm Vòng đời DevOps

🎯 Mục tiêu môn học

Trải nghiệm và làm chủ vòng đời DevOps: Plan → Code → Build → Test → Deploy → Monitor kết hợp công cụ tự động hóa GitHub Actions.


🛠️ Kỹ năng thực hành trong Lab 1:

  • Quản lý mã nguồn với Git & GitHub Repository
  • Xây dựng CI/CD Pipeline với GitHub Actions Workflow (.yml)
  • Triển khai tự động hóa (Automated Continuous Deployment) lên GitHub Pages
  • So sánh phương pháp DevOps hiện đại và cách triển khai thủ công truyền thống
